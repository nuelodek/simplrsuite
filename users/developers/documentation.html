API Integration

Use Simplr's API with your project. Authenticate using an API key.

Authentication


<?php
    $apiKey = 'YOUR_API_KEY';
    $url = 'https://simplr.com.ng/api/endpoint';

    $options = [
        'http' => [
            'header' => "Authorization: Bearer $apiKey"
        ]
    ];
    $context = stream_context_create($options);
    $response = file_get_contents($url, false, $context);
    echo $response;
?>

Available Endpoints

GET /api/get-projects – Get list of projects
POST /api/create-task – Create a task

Fetch Projects


<?php
$projectsUrl = 'https://simplr.com.ng/api/get-projects';
$projects = file_get_contents($projectsUrl);
echo $projects;
?>

Create a Task


<?php
$taskUrl = 'https://simplr.com.ng/api/create-task';
$data = [
    'task_name' => 'New Task',
    'project_id' => 123
];
$options = [
    'http' => [
        'header'  => "Content-type: application/x-www-form-urlencoded",
        'method'  => 'POST',
        'content' => http_build_query($data)
    ]
];
$context = stream_context_create($options);
$result = file_get_contents($taskUrl, false, $context);
echo $result;
?>
